清理记录、复用任务、验证规则

在已有多账号与任务工作台上，补齐日常维护和排错入口。

归档删除与清理

单条、多选、筛选、会话或仅图片清理，先预览范围再确认。只清本地内容，保留任务和发送账本，防止补档或合并备份重新出现。

任务复制与模板

复制为关闭的副本，或从三个内置模板开始。JSON 导入先成为未绑定草稿，重新选择对象并验证后才能开启。

多样例一起验证

最多保存 20 条应匹配和不应匹配样例，可检查准确回复。全部通过后再启用，草稿验证不发送消息。

异常处理入口

连接、限流、存储、暂停、待恢复和待核对结果有原因与处理路径，支持诊断预览，不自动恢复发送或重试。

日常使用

从登录到后台运行

  1. 01

    登录并核对身份

    按 PKG 向导安装到“应用程序”，打开后登录 Telegram 并确认身份。自定义 API 在高级设置。

  2. 02

    选择需要的功能

    在准备向导中测试提醒、选择归档。在任务管理保存模板和样例，预览通过后再确认开启。

  3. 03

    留在菜单栏

    关闭窗口继续运行，随时暂停或查看状态。退出应用会停止全部账号。

使用边界

开始前了解这些

普通用户需要自己申请 API 吗？

有内置配置的安装包只需登录 Telegram；自定义 API 放在高级设置。当前内部包使用官方测试配置，正式产品 API 待完成。

电脑睡眠后还能执行吗？

睡眠、合盖、退出应用或网络不可用时不能实时处理。可选防闲置睡眠不能覆盖主动睡眠或合盖，恢复后按时限规则处理新提示，不补发重启前旧消息。

自动回复会直接开启吗？

不会。新对象或规则先保存为仅提醒，预览并确认后才启用。重启或身份恢复后，逐账号确认，再在准备与恢复向导中选择恢复原先开启的任务。固定回复默认本地有效期 5 分钟，可自定义。

发送成功是否表示考勤已经登记？

编号模式需要匹配同编号登记回执。固定回复当前没有通用回执解析，只显示“已发送，登记未核实”，需要在原会话确认实际业务结果。

模板能修改和保存吗？

可以。在任务管理新建或编辑任务，匹配模板和测试样例分别保存。编号查岗选择“从提示提取关键词”，可从样例生成含编号、分钟数和关键词占位符的提取模板；关键词可随每条消息变化。修改执行条件只暂停该任务，其他任务保持运行。

聊天和凭据存在哪里？

资料保存在本机，按账号隔离，不上传到产品云端。Telegram 连接仍访问其服务。会话和 API 不随普通备份导出，本地备份未加密，源码仓库不包含真实消息和凭据。

安装后怎么使用和更新？

推荐双击 PKG，按“继续 → 安装”完成安装，再从“应用程序”打开即讯（原通讯助手）。为兼容旧安装，磁盘路径仍为 /Applications/通讯助手.app，资料目录和应用标识不变。系统可能要求管理员验证。升级前退出应用，安装器只替换应用，保留账号和资料；之后在准备与恢复向导中核对账号和原先开启的任务，再选择恢复。DMG/ZIP 为备用。Intel、自动更新、正式签名及公证尚未完成。

72 小时验收通过了吗？

尚未通过。0.5.0 在本机升级并恢复原任务后独立计时，起止时间见验收记录。会核对实际覆盖、连接、资源、采样缺口和进程更换；到期本身不等于通过，旧版计划升级中断的时间不拼接。

为什么系统提示无法验证开发者？

目前安装器尚未完成 Developer ID 签名与 Apple 公证，不能保证联网下载后顺畅安装。请核对 Release 来源与 SHA256，参考 Apple 官方说明；无需关闭系统安全保护。当前 PKG 已验证安装结构和向导，干净 Mac 的完整安装仍待验收。
