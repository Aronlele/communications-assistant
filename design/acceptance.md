# 验收范围

这里保存可随源码共享的脱敏范围。本机真实账号、消息、Token、会话及观察样本不进入仓库。原 0.3.1 已完成 124 项产品测试和 36 项参考测试，原生多账号探针 18 项；仓库边界检查独立增加，最新实际数量以 CI 结果为准。

| 范围 | 已有证据 | 边界 |
| --- | --- | --- |
| 登录与身份 | 用户真实登录，异常状态模拟及取消/重发回归 | 不声称所有真实限流、封禁与异常都在线复测 |
| 提醒与语音 | 系统提交、用户通知中心和语音确认、点击定位 | 专注模式展示由系统决定 |
| 归档 | 真实文字、图片编辑/删除；中文搜索、分页和游标回归 | 不承诺平台删除后仍可补齐 |
| 关键词自动回复 | 测试机器人发送/回执/去重，旧工作机器人曾有登记样例 | 只对已验收模板有效 |
| 自定义固定回复 | 测试机器人实际收到一次固定内容，非匹配消息未发送 | 无通用回执解析，发送不代表工作登记 |
| 多账号 | 两真实账号曾同时在线，通知定位、归档及发送隔离 | 当前在线账号数量按用户选择，不作为永久双账号观察 |
| 恢复与数据 | 原生恢复、备份、错误账号拒绝、磁盘不足与未知发送回归 | 未对真实工作资料做破坏性故障注入 |
| 包与分发 | 本机严格签名、镜像/ZIP、打包引擎检查 | 临时签名；干净 macOS 14、公证待验收 |
| 长期运行 | 本机 0.3.3 独立 72 小时观察进行中 | 0.3.1 因计划升级中断，不拼接为新版通过 |

0.2 的启动、提醒管线、5 万条搜索和关窗资源结果保留为历史基准，不代表新版全量性能通过。10 秒提醒合并结束后单独计处理耗时。CPU 用相邻样本累计时间差，跳过睡眠、缺失和进程更换。

0.3.2 主要为仓库/文档/发布流程与版本文案整理，自动回复逻辑未改。需要对新包验证源码测试、原生编译、打包演示隔离、签名、ZIP/DMG、配置来源；单独发布结果不能标成完整 72 小时通过。

仍待覆盖：完整 VoiceOver/Tab、干净旧系统、网络切换、高频来信及最新实际任务机器人登记。实际运行和授权状态以用户应用及本机记录为准，仓库不提供可替代真实配置的记录。

## 0.3.3 账号移除与升级

新增回归覆盖空入口移除、旧入口移除后重启、已登录与未确认请求拒绝、最后入口保护、目录写入失败回滚、后台移除隔离，以及排队请求不再访问已关闭数据库。原生探针覆盖确认账号与请求账号一致、移除后自动切换和完成提示。真实升级另核对会话、规则、归档与发送账本；不以旧版本的观察时间代替新版连续 72 小时。

本机升级检查：0.3.1 → 0.3.3（构建 12），两个原有账号恢复连接；全部已保存设置一致（除自动回复启用时间），归档和执行账本数量未减少，原先开启的固定回复规则已恢复。账号移除确认框实机打开并取消，未改动真实账号列表；实际删除在隔离的打包引擎数据目录通过。173 项 Python、26 项多账号原生和 9 项恢复检查通过。旧版连续观察因计划升级中断，新版需单独观察。

## 0.3.3 安装交付补充

新增 PKG 向导，实际载荷与已验收应用一致，未修改运行中的应用或用户资料，也未重置观察。检查固定 `/Applications`、非重定位升级、架构/最低系统要求、退出元数据、无安装脚本、完整载荷及严格签名；系统安装器已实机验证欢迎、说明和安装确认页。未点击最终安装，干净 Mac 的完整安装与 Gatekeeper 体验仍待验收。当前 PKG 未签名、公证未完成。
