# 通讯助手产品设计说明书

修订 1.3，对应 0.4.0 测试版，72 小时观察中。目标是我们自己长期使用的 macOS 通讯辅助产品，先完成可配置、可恢复和可核对的内部体验，再评审对外发布。原始 [v1.0 Word](通讯助手产品设计说明书_v1.0.docx) / [PDF](通讯助手产品设计说明书_v1.0.pdf) 保留为历史基线。

## 产品范围

原生主窗口与菜单栏；多账号同时连接；系统提醒与语音；选择性本地归档与检索；明确授权的关键词或固定回复；运行状态、数据管理和诊断。普通 Telegram 聊天、群管理继续通过原客户端操作。

不建设团队、收费、云端全天运行、AI 回复或通用工作流。每账号最多 50 个独立任务，可分别绑定多个对象；不支持群聊自动回复、自由正则、脚本和任意变量提取。自定义回执的进一步扩展须先确定可可靠关联的场景。

## 首次使用

PKG 安装向导 → 从应用程序打开 → 登录 Telegram → 本人身份确认 → 测试通知 → 选择归档会话 → 按需配置规则。安装器固定目录，只替换应用，升级保留资料；DMG/ZIP 备用。普通用户不申请 API；内置产品配置由维护者打包，自定义 API 在高级设置。当前测试包只有官方 TEST ONLY 配置，正式 API 未完成。

登录支持国家区号、粘贴号码、验证码重发、两步验证与取消恢复。验证码及密码不保存。会话复用后仍确认身份，自动回复主动重新启用。退出尝试远端撤销，失败如实提示，归档默认保留。

## 多账号

左下角头像、姓名和状态用于切换/添加。真实头像缺失时显示姓名首字。各账号独立会话、数据库、归档、图片、规则、暂停、静音、设备配置及自定义 API。重复身份不能添加，后台账号不因切换而停止。通知保留来源账号并定位正确消息。

系统通知权限、登录启动和防闲置睡眠为全应用共用。旧入口保留原目录，新入口使用随机目录；页面操作只作用当前账号，退出整款应用停止全部账号。

## 提醒

默认入站私聊与提及，仅来源通知，语音及正文默认关闭。支持具体会话覆盖、排除、按周静音。10 秒合并同会话连续提醒；2 秒目标计合并结束后的本地处理。系统提交不等于实际展示，语音区分排队、播放、完成、取消和失败。队列最多 50 项，过期 60 秒合并摘要。

点击通知切到来源账号并定位消息。会议静音/暂停提醒只影响提醒，不暂停归档和已授权发送；专注模式展示由系统决定。

## 归档与数据

默认关闭，逐私聊/群组选择。可从最近 300 条、仅新消息或指定日期开始，分页事务保存消息与游标，实时事件不跳过待补历史。文字、回复、转发、编辑和可定位删除状态；图片默认关闭，每张 10 MB，失败有限重试。限时消息不长期保存，其他媒体不假称文件已下载。

三栏列表/结果/上下文；按关键词、会话、发送者和日期搜索。TXT/JSON 导出预览可含图片。主动导入旧文字、明确引用的图片和去重账本；本地备份/恢复不含登录会话和 API，恢复后关闭发送与在线策略。当前备份未加密。

默认保留 30 天、容量 1 GB；80% 提示、满额暂停，磁盘无法安全写入时归档和依赖账本的新发送停止。普通归档清理不删除永久去重账本。

## 受控自动回复

每账号最多 50 个独立任务，旧规则原位保留为第一条任务。用户选择已解析的固定对象，机器人默认允许，普通联系人需显式允许，不能选本人。保存执行条件变更仅暂停该任务；修改名称或样例不关闭正在运行的任务。匹配模板与测试样例分别持久化；真实样例预览结果、内容和身份后才能确认启用。

编号关键词模式：默认兼容现有完整结构，也可保存由 {number}、{minutes}、{keyword} 和可选 {name} 组成的精确提取模板；单个编号/关键词/分钟数；按真实创建时间和正常响应期限发送，不把额外超时区间当作自动补发窗口。编号唯一键为账号、对象、编号，同编号回执才确认；正常截止后 5 分钟仍无回执才提示核对。

固定回复模式：用户填写全文或包含匹配文本和 1–100 字符单行内容。全文匹配仅规范首尾空白和换行，不猜测语义。用户设置本地有效期 1–1440 分钟，默认 5 分钟；无业务时限样例时不能当作机器人正常时限。以账号、对象、来源消息 ID 去重，新消息可触发新任务。

两种模式都只处理对象直接发来的新私聊，拒绝转发、via-bot、本人发出、旧消息及过期消息。支持独立允许发送时段。发送前事务落盘；超时、异常或退出中结果不明不自动重试。固定回复无可靠关联回执时记为“已发送，登记未核实”，不假称考勤已登记。

## 运行与交付

关窗保留菜单栏，退出停止引擎；重连、睡眠恢复、单写入者锁和一分钟内最多三次引擎恢复。登录启动、防闲置睡眠主动选择，不能保证合盖或手动睡眠期间执行。在线状态请求为实验能力，默认关闭，不发送/删除收藏夹消息。

Apple Silicon，声明最低 macOS 14，但干净旧系统尚待验证。测试版手动下载更新；Developer ID、公证、正式 API、源码许可及正式支持仍待完成。源代码仓库、Release 与 GitHub Pages 展示站均公开访问，下载无需 GitHub 登录；公开访问不代表已完成正式产品发布或授予开源许可证。

## 验收与尚未收口

代码回归、原生状态、真实发送和长期观察分别记录，不能用任一结果替代全链路。详见 [验收范围](acceptance.md)。0.4.0 测试版增加任务结果筛选、分页和原消息定位，以及跨账号状态总览、首次使用和批量恢复向导。待同步消息精确计数等仍需按实际需求补齐；完整 VoiceOver、干净系统、网络切换及高频消息仍需对应证据。

面向普通用户的发行条件与后续体验改进见 [公开推广前产品评估](public-release-review.md)。PKG 安装器并不替代正式 API、签名公证和干净机器验收。
