# 即讯产品设计说明书

修订1.8，当前版本0.6.1（构建18）。保留多账号、多任务、归档清理、配置向导、网络代理、安全升级与加密备份，补齐群组系统事件与受控旧空记录补全。真实升级和任务恢复见验收记录。本轮用户取消72小时观察与自动复查，长期稳定性未验证，旧版本时长不拼接。原名“通讯助手”，安装与资料标识沿用以兼容升级。原始Word/PDF保留为历史基线。

## 产品范围

原生主窗口与菜单栏；多账号同时连接；系统提醒与语音；选择性本地归档与检索；明确授权的关键词或固定回复；运行状态、数据管理和诊断。普通 Telegram 聊天、群管理继续通过原客户端操作。

不建设团队、收费、云端全天运行、AI 回复或通用工作流。每账号最多 50 个独立任务，可分别绑定多个对象；不支持群聊自动回复、自由正则、脚本和任意变量提取。自定义回执的进一步扩展须先确定可可靠关联的场景。

## 首次使用

PKG 安装向导 → 从应用程序打开 → 登录 Telegram → 本人身份确认 → 测试通知 → 选择归档会话 → 按需配置规则。安装器固定目录，只替换应用，升级保留资料；DMG/ZIP 备用。普通用户不申请 API；内置产品配置由维护者打包，自定义 API 在高级设置。当前测试包只有官方 TEST ONLY 配置，正式 API 未完成。

登录支持国家区号、粘贴号码、验证码重发、两步验证与取消恢复。验证码及密码不保存。会话复用后仍确认身份，自动回复主动重新启用。退出尝试远端撤销，失败如实提示，归档默认保留。

## 多账号

左下角头像、姓名和状态用于切换/添加。真实头像缺失时显示姓名首字。各账号独立会话、数据库、归档、图片、规则、暂停、静音、设备配置及自定义 API。重复身份不能添加，后台账号不因切换而停止。通知保留来源账号并定位正确消息。

系统通知权限、登录启动和防闲置睡眠为全应用共用。旧入口保留原目录，新入口使用随机目录；页面操作只作用当前账号，退出整款应用停止全部账号。

## 提醒

默认入站私聊与提及，仅来源通知，语音及正文默认关闭。支持具体会话覆盖、排除、按周静音。10 秒合并同会话连续提醒；2 秒目标计合并结束后的本地处理。系统提交不等于实际展示，语音区分排队、播放、完成、取消和失败。队列最多 50 项，过期 60 秒合并摘要。

点击通知切到来源账号并定位消息。会议静音/暂停提醒只影响提醒，不暂停归档和已授权发送；专注模式展示由系统决定。

## 归档与数据

默认关闭，逐私聊/群组选择。可从最近 300 条、仅新消息或指定日期开始，分页事务保存消息与游标，实时事件不跳过待补历史。文字、回复、转发、编辑和可定位删除状态；图片默认关闭，每张 10 MB，失败有限重试。限时消息不长期保存，其他媒体不假称文件已下载。

三栏列表/结果/上下文；按关键词、会话、发送者和日期搜索。TXT/JSON 导出预览可含图片。主动导入旧文字、明确引用的图片和去重账本；本地备份/恢复不含登录会话和 API，恢复后关闭发送与在线策略。业务备份可选密码加密，当前数据库与登录会话本身未因此加密。

默认保留 30 天、容量 1 GB；80% 提示、满额暂停，磁盘无法安全写入时归档和依赖账本的新发送停止。普通归档清理不删除永久去重账本。

## 受控自动回复

每账号最多 50 个独立任务，旧规则原位保留为第一条任务。用户选择已解析的固定对象，机器人默认允许，普通联系人需显式允许，不能选本人。保存执行条件变更仅暂停该任务；修改名称或样例不关闭正在运行的任务。匹配模板与测试样例分别持久化；真实样例预览结果、内容和身份后才能确认启用。

编号关键词模式：默认兼容现有完整结构，也可保存由 {number}、{minutes}、{keyword} 和可选 {name} 组成的精确提取模板；单个编号/关键词/分钟数；按真实创建时间和正常响应期限发送，不把额外超时区间当作自动补发窗口。编号唯一键为账号、对象、编号，同编号回执才确认；正常截止后 5 分钟仍无回执才提示核对。

固定回复模式：用户填写全文或包含匹配文本和 1–100 字符单行内容。全文匹配仅规范首尾空白和换行，不猜测语义。用户设置本地有效期 1–1440 分钟，默认 5 分钟；无业务时限样例时不能当作机器人正常时限。以账号、对象、来源消息 ID 去重，新消息可触发新任务。

两种模式都只处理对象直接发来的新私聊，拒绝转发、via-bot、本人发出、旧消息及过期消息。支持独立允许发送时段。发送前事务落盘；超时、异常或退出中结果不明不自动重试。固定回复无可靠关联回执时记为“已发送，登记未核实”，不假称考勤已登记。

## 运行与交付

关窗保留菜单栏，退出停止引擎；重连、睡眠恢复、单写入者锁和一分钟内最多三次引擎恢复。登录启动、防闲置睡眠主动选择，不能保证合盖或手动睡眠期间执行。在线状态请求为实验能力，默认关闭，不发送/删除收藏夹消息。

Apple Silicon，声明最低 macOS 14，但干净旧系统尚待验证。提供应用内检查与验证下载，确认后由系统安装器升级；Developer ID、公证、正式 API、源码许可及正式支持仍待完成。源代码仓库、Release 与 GitHub Pages 展示站均公开访问，下载无需 GitHub 登录；公开访问不代表已完成正式产品发布或授予开源许可证。

## 0.5.0 已实现的体验补齐

归档清理位于归档页，可右键单条、勾选多条、按当前筛选或会话清理，并可仅删除本地图片。确认前冻结消息集合并预览账号、数量及图片占用；确认后不可撤销，不删除平台消息或发送账本。会话清空明确区分继续归档新消息与停止归档，已有关闭状态不会自动开启。清理会同步移除应用迁移快照的对应内容，不修改用户另存的外部备份。

任务复制生成关闭的副本，原任务不变；三个内置模板覆盖编号、固定回复和自定义关键词。模板 JSON 不含账号、对象或发送授权，导入先进入未绑定草稿。每任务可保存最多20条正反样例及可选预期回复，验证草稿不修改执行条件，重新开启前需全部通过；仅改样例不停止原先已运行的任务。

异常处理为全局工具栏、任务结果和账号总览中的独立面板，按当前账号提供原因、下一步、诊断与对应页面；不会自动解除暂停、恢复发送或重试未知结果。

0.5.0已完成本机原位升级：两个账号在线，两条原任务恢复，原业务配置与账本保留。随后经用户明确要求升级至0.6.0，完整备份后保留两个原账号、配置和账本，恢复原两条任务；旧观察按计划结束。

## 0.6.0：四项产品体验

以下能力已完成独立实现、隔离验收和本机升级恢复。本机现已升级0.6.1，原能力保留；本轮用户取消72小时观察，不沿用旧版观察结论。具体通过范围与待验证项目见验收记录。

1. 任务配置向导：对象、提示样例、回复方式、验证、保存分步完成，复用原任务保存/启用接口。草稿验证给出差异位置和处理建议；不放宽已有精确匹配、不发送测试消息、不更改其他任务。新任务保存后仍关闭发送。
2. 网络与代理：按账号配置直连、SOCKS5或HTTP CONNECT；密码仅由原生钥匙串保存。保存供下次连接生效，立即应用必须明确确认并仅重连该账号、保留原任务恢复意图。诊断使用独立无登录探测，不创建第二个Telegram会话、不影响工作连接，区分端口可达与真实账号登录成功。
3. 检查更新与安全升级：固定官方GitHub仓库，正式/测试版本可选择，过滤草稿及不匹配的架构/附件，校验远端SHA256和完整下载。提供版本说明、升级前账号/任务清单、受保护的完整本机回退备份和系统安装器入口；校验或备份失败时不退出、不覆盖应用。未签名/未公证的测试包明确提示并要求确认，不自动安装、不承诺无感恢复。
4. 账号资料与加密备份：发现被移除入口所保留的本地资料，预览账号及计数，确认后重新挂回原目录；拒绝重复身份、非法路径和目录变化。恢复不启用发送。业务备份可选密码加密，使用成熟库的认证加密和密码派生，密码不保存；错误密码/篡改文件在写入目标资料前拒绝。普通备份继续不包含登录会话或API凭据。

### 本轮成功标准

- 向导及失败解释有合成正反样例、草稿无副作用和任务隔离证据。
- 两种代理握手与超时/认证失败、保存不重连、账号隔离及凭据不落库/诊断输出有证据。
- 更新元数据、版本/来源/附件限制、哈希不符、下载失败、备份失败均保持原应用与任务；完整升级仅在隔离副本演练，不实际替换工作版。
- 保留资料重新挂回、重复/损坏目录拒绝，加密备份往返、错误密码/篡改/错误账号拒绝、原明文备份兼容和发送账本保留均通过。
- 原生界面与实际打包引擎验收；开发期间保持工作版，用户另行授权后备份升级、核对原配置和启用集合；本轮72小时观察按用户要求取消，长期稳定性未验证。


## 0.6.1：群组系统消息

保留原账号、配置及发送范围。采用独立服务消息事件监听；将明确的系统事件转成文字及“群组系统消息”标签，沿用schema5原消息字段，无需迁移工作数据库。历史与实时归档一致，未知类型不冒充普通文字，不猜造缺失身份。

旧空记录修复是逐群、逐批的显式操作：本地预览冻结最多100条记录、5分钟有效，确认后只读平台对应消息并验证会话、编号、日期；原记录发生变化、账号恢复代次变化、删除、暂停、正在补档或容量受限时不写。不可访问、其他类型和保护内容保持原样并报告，可手动预览下一批，不自动循环重试。不修改任务、归档开关、历史游标或发送账本。

独立验收已覆盖真实SDK服务消息类型、实时监听、历史持久化/搜索/导出/备份、旧空记录往返、缺失/错误/限流/网络失败、删除并发及账号隔离。随后按用户要求实际升级0.6.1，两个原账号和两条原任务恢复，3条旧空记录经现有引擎回读全部补全，其余消息、配置、游标及账本保持一致。用户已取消72小时观察及自动复查，不启动新版观察。
