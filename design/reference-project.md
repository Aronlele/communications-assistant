# 参考项目与产品关系

根目录保留用户提供的 TgBot-master Python/Docker 实现，主要是个人 Telegram 登录、私聊/提及来源播报、文字图片归档、在线时段及固定查岗关键词回复。Windows 语音服务与容器通过 HTTP 连接。

macOS 产品复用 auto_checkin.py 的固定结构解析器与期限规则，其他连接、归档和系统交互在 macos/ 下实现；不依赖 Docker 或 Windows 语音服务。

| 参考能力 | 产品改进 |
| --- | --- |
| 终端、环境变量、单账号 | 原生界面、独立账号、身份核对与恢复 |
| Windows 语音服务 | macOS 通知、系统语音、静音与定位 |
| 文本/图片及 JSON 游标 | SQLite、事务分页、编辑删除、搜索导出和备份 |
| 固定关键词与 JSON 发送状态 | 事务账本、预览、显式启用、固定内容自定义 |
| 在线上报与收藏夹发删 | 默认关闭的状态实验，不自动发删收藏夹 |
| 控制台日志 | 状态、活动与无凭据/正文的诊断 |

参考脚本仍可自行配置运行：复制 .env.example 填写本地 API，交互登录后启动容器；Windows 语音脚本需安装其依赖。示例不再预设真实群名或个人设备信息。参考项目的来源许可尚未核实，私有存档不表示获准开源。
