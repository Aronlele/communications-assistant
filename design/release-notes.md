# 通讯助手 0.4.0 测试版 · 多任务与恢复向导

本版增加多任务管理、任务结果中心、所有账号总览，以及首次使用和恢复向导。源码、PKG/DMG/ZIP 安装包、展示页和使用说明同步发布。**72 小时验收仍在观察中，尚未通过**。本轮独立观察为 2026-10-15 12:06 至 2026-10-18 12:06（北京时间，预计）；旧版计划升级中断的观察不合并计时。

## 使用变化

每账号可保存最多 50 个任务，分别选择机器人或明确允许的普通联系人，设置关键词提取或固定回复、有效期、优先级和发送时段。同一来源消息跨任务只提交一次。任务匹配重叠时提示同一对象的其他任务，并按优先级和列表顺序执行。

匹配模板与测试样例分别保存。标准查岗样例能生成 `{number}`、`{minutes}`、`{keyword}` 提取模板，可选 `{name}`；其余文字和换行精确匹配。内置查岗识别继续兼容，无需把每次变化的“香蕉”等关键词保存为固定回复。

结果中心可筛选任务和状态、分页、查看原消息；发送成功、登记回执确认和未知结果分别展示。删除任务保留发送账本和历史记录，已有编号的迟到回执仍会核对。

总览同时显示账号连接、任务数量、暂停、待恢复及待核对结果；从卡片进入对应账号，其他账号继续运行。准备向导可按需配置通知、归档和任务。重启后保留之前的启用意图，核对身份后选择恢复，手动关闭的任务保持关闭，不补发旧提示。

## 升级与数据

原有账号目录、登录会话、设置、归档和账本保留；旧规则原位显示为第一条任务。只改任务名称或样例不关闭任务，修改执行条件则只暂停该任务。升级需短暂退出旧应用，新功能不会在旧进程中热加载。

schema 4 增加任务归属，迁移前保存数据库快照。旧 schema 3 的业务备份在临时副本升级，新备份包含任务和样例，恢复后关闭发送并重新预览。旧版应用不能直接打开 schema 4；不能用旧快照覆盖新发送账本后直接恢复自动发送。

## 验收边界

已通过 195 项 Python 回归、42 项原生状态检查；本轮还包含原生状态探针、隔离界面操作、实际打包引擎和安装器载荷检查，并对本机数据只读快照进行迁移演练。界面的回执、未知结果和恢复状态使用明确的合成演示数据，不代表向工作机器人进行过测试发送。

本机已完成用户授权的真实账号切换并恢复原有任务，本版完整 72 小时仍需独立观察；不得沿用 0.3.3 的观察时间。固定回复缺少可靠关联回执时仍只确认发送，不认定考勤登记。正式 API、Developer ID 签名、公证、干净旧系统和完整可访问性仍待验收。
