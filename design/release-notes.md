# 即讯 0.7.0 测试版 · 交互稳定与恢复帮助

- **交互稳定**：普通只读操作不触发全局加载闪烁；空结果保持列表与列宽，筛选变化清理旧上下文；合并重复搜索，拒绝旧查询、分页及切换账号后迟到的结果和错误。任务结果只在相关数据变化时刷新。
- **归档范围与类型**：按系统消息、图片、其他附件和文字筛选，查询、导出、筛选清理范围一致；查看本机保存时间范围、条数、起始依据与同步状态，不代表平台完整历史。
- **任务检查解释**：展示本次启动后绑定对象的最近检查原因，仅保留内存，不记录正文或关键词。未知发送不自动重试，固定回复仍不认定对方已确认。
- **备份与帮助**：记录成功创建和校验时间；“仅校验备份，不恢复”先验证完整性和归属，不关闭任务。提供恢复检查帮助；在线状态实验设置收进高级设置，原配置保留。

## 安装与使用

Apple Silicon，声明最低macOS14，本机验收环境macOS27.0.1。首选PKG安装向导，DMG/ZIP备用，公开下载无需GitHub登录。升级前备份并正常退出，原位安装保留账号、配置、归档与账本。之后逐账号核对身份，在“准备与恢复”仅恢复原先开启的任务，不补发重启前旧提示。

兼容安装位置仍为`/Applications/通讯助手.app`，资料目录、钥匙串和应用标识不变，数据库仍schema5。业务备份不含登录会话、API和代理密码；完整升级回退副本含登录会话，仅留本机，勿分享。

## 验收与限制

260项Python、95项原生检查，以及独立界面、两个账号只读迁移副本、冻结引擎、PKG载荷/权限、DMG/ZIP完整性验收通过。独立界面结果页静置64秒无额外查询、短只读操作未挂载全局进度指示；有/无结果列位置一致。本机已升级0.7.0构建19，两个原账号在线、两条原任务按原启用集合恢复；配置和账本保留，待恢复与发送积压为0。工作版有/无结果切换列宽一致，旧上下文清除。真实升级与恢复另见[逐项验收记录](https://github.com/Aronlele/communications-assistant/blob/main/design/acceptance.md)，独立测试不等同于真实业务发送或对方确认。

按用户要求不启动72小时观察和自动复查，长期稳定性未验证，历史中断时长不拼接。
