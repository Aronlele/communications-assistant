# 即讯 0.6.0 测试版 · 配置、连接、升级与恢复

本版新增四项能力：

- **任务配置向导与匹配失败解释**：四步选择对象、粘贴完整提示、设置固定回复或动态关键词、验证后保存。失败指出行列和空格/换行差异，不放宽原匹配条件。新任务保持关闭，核对固定身份后单独开启。
- **网络诊断与应用内代理**：按账号设置直连、SOCKS5、HTTP CONNECT；密码仅由钥匙串保存。无登录链路测试不发送消息、不改变当前连接。保存供下次启动或主动重连使用；立即应用只中断当前账号，须确认并恢复原任务。
- **检查更新与安全升级**：固定官方仓库、可选测试渠道，校验版本、架构、完整长度和SHA256。先备份全部本机资料、旧应用及偏好，再由用户确认交给系统安装器；校验或备份失败保留原应用运行。
- **账号资料恢复与加密备份**：预览并重新挂回已移除入口保留的资料，拒绝重复身份、损坏或变化目录。AES-256-GCM加密业务备份，密码不保存；错误密码、篡改或错误账号在写入前拒绝。仍兼容原明文备份。

多账号、多任务、归档清理、任务复制/模板、多样例验证与异常入口继续保留。

## 安装与升级

Apple Silicon，声明最低macOS14，本机验证环境macOS27.0.1。首选PKG安装向导，DMG/ZIP备用，公开下载无需GitHub登录。升级前完整备份、正常退出即讯，安装到原位置，再逐账号确认身份，在“准备与恢复”仅恢复此前开启的任务。不补发重启前旧提示。

应用磁盘路径仍为`/Applications/通讯助手.app`，原账号、资料目录、配置和发送账本保持兼容；数据库仍为schema5。降级须核对兼容性并保留完整升级前资料，旧版不能直接读取不兼容数据。

业务备份不含登录会话、API或代理密码，密码遗失无法恢复；应用数据库和登录会话本身未因此加密。**升级回退副本包含登录会话，仅存本机受保护目录，不可分享。** 固定回复“已发送，登记未核实”不能视为考勤登记成功。
