# 通讯助手 0.3.2 内部测试

本版将已有原生产品整理为可维护的私有仓库，补齐产品首页、设计、架构、测试、构建及发布流程，并修正版本显示和过期使用说明。支持多账号、系统提醒、本地归档、关键词与自定义固定回复。

## 安装

Apple Silicon；声明最低 macOS 14，但干净旧系统尚未验收。本机实际验证为 macOS 27。下载 DMG 拖入应用程序，或者 ZIP 解压后运行。升级前退出应用，保留本机资料；重启后确认身份并重新开启所需规则。

## 配置与权限

本次内部包沿用已授权的 Telegram 官方 TEST ONLY 配置，正式产品 API 未就绪。源码不含 API 配置、Token、会话或真实资料。仓库和 Release 私有，下载需要授权。

当前为临时签名，未经 Developer ID 签名和公证；不保证干净联网下载环境的 Gatekeeper 体验。不要通过关闭系统保护来宣称安装已验收。

## 结果与边界

固定回复缺少通用登记回执格式时只记已发送、登记未核实。每账号当前一个对象，直接私聊；不支持群聊自动回复、自由正则或脚本。电脑睡眠、退出或断网时不能实时处理，重启前旧提示不补发。

本机 166 项回归、18 项多账号原生探针、9 项恢复探针通过；打包双演示、自定义规则、搜索、备份、退出，以及严格签名、DMG、ZIP 检查通过。展示页精确/包含预览、空回复校验、桌面和手机布局通过。旧版性能和 72 小时观察不作为本版连续通过证据。完整 VoiceOver、干净旧系统、最新实际任务登记及完整稳定性仍有待验收。

附件 SHA256SUMS.txt 提供 DMG、ZIP 和离线 site-preview.zip 的校验。展示页不含真实账号或聊天，离线预览无需登录；下载链接访问私有 Release 时需 GitHub 授权。
