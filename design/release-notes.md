# 即讯 0.4.2 测试版 · 更名与安装修复

通讯助手现更名“即讯”。窗口、菜单栏、通知、安装向导、展示页与使用说明统一更新；多账号、多任务、结果中心和恢复向导的操作保持兼容。

## 安装修复

修复内置 API 配置以 0600 权限打包，在 PKG 安装为管理员所有后，普通用户无法读取并误提示缺少配置的问题。包内配置改为 0644，私有构建源仍为 0600。安装包检查现在同时验证实际载荷的资源读取、目录遍历及程序执行权限，并覆盖拒绝不可读资源和不可执行目录/程序的回归。

原 v0.4.1 PKG 存在上述权限问题，请新安装用户使用本版；不覆盖历史附件。已安装且正常运行的本机 0.4.1 已完成本地权限修复。

## 兼容与验收

保留 `/Applications/通讯助手.app` 的实际磁盘路径、bundle ID、钥匙串服务和原资料目录，确保覆盖同一个应用，保留现有账号、归档、自动回复配置与发送账本；应用展示名称为“即讯”。现有自定义设备字段不改，新账号默认设备名为“即讯 macOS”。升级前正常退出应用，升级后确认账号并在“准备与恢复”中恢复原有任务。

本次发布不替换本机正在运行的 0.4.1 构建 14，不修改现有账号和自动回复。其独立 72 小时观察从 2026-10-16 10:29 至预计 2026-10-19 10:29（北京时间），仍在观察中、尚未通过。0.4.2 的真实账号升级与独立 72 小时观察尚未开展，不能沿用旧版结果。

完整代码回归、原生状态检查、打包引擎、实际 PKG 载荷与权限、DMG/ZIP 完整性及临时签名需通过后发布；详见验收记录。仍为测试版：使用官方 TEST ONLY API，应用临时签名、安装器未签名且未公证；正式 API、签名公证和干净旧系统安装仍待完成。固定回复“已发送，登记未核实”不能当作实际考勤登记成功。
