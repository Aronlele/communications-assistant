# 即讯 0.5.0 测试版 · 清理、模板与异常处理

本版新增四项日常能力：

- **归档删除与清理**：单条、多选、当前筛选、会话和仅图片清理，预览范围后输入“删除”确认。只处理本地内容，保留任务及防重账本；删除标记阻止补档或业务备份合并复活内容。外部另存备份不受影响。
- **任务复制与模板**：副本默认关闭；三个内置模板及 JSON 导入导出。导入为未绑定草稿，不携带账号或发送授权，需重新绑定、验证和确认。
- **多样例验证**：最多 20 条正反样例、总长 8000 字符，支持准确预期回复。整组通过后才能重新开启；修改样例不打断其他任务。
- **异常处理入口**：解释连接、限流、存储、暂停、待恢复及需核对结果，提供跳转与诊断预览，不自动恢复发送或重试未知结果。

## 安装与升级

Apple Silicon，声明最低 macOS 14，本机验证环境 macOS 27.0.1。首选 PKG 安装向导，DMG/ZIP 备用。公开下载，无需 GitHub 登录。

先正常退出即讯，安装到原位置，再逐账号确认身份，在“准备与恢复”中仅恢复此前开启的任务。不补发重启前旧提示。应用磁盘路径仍为 `/Applications/通讯助手.app`，原账号、资料目录、配置和发送账本保持兼容。

本版升级至数据库 schema 5，并保存迁移前快照，兼容旧业务备份。**旧版不能直接读取新版数据**；降级前须恢复完整升级前资料。删除仅影响本地，执行前请核对范围；固定回复“已发送，登记未核实”不能视为考勤登记成功。
