# 通讯助手 0.3.3 测试版

修复左下角账号列表缺少移除入口的问题。点击账号名称后可选择“移除当前账号…”，确认后移除已退出或未登录的入口；本地归档、规则、发送账本和自定义配置保留，其他账号继续运行。已登录账号需先退出或取消登录，至少保留一个登录入口。

移除旧版入口后可以正常重启；写入账号目录失败时回滚列表，排队中的旧请求不能访问已移除账号。重新添加账号不会自动合并旧归档，可通过原目录的本地备份恢复。

## 升级与使用

Apple Silicon；声明最低 macOS 14，干净旧系统仍待验收。升级前正常退出应用，优先使用 PKG 向导，或用 DMG/ZIP 中的应用替换旧版，保留本地应用资料。重启后逐账号确认身份，并重新开启原先需要的自动回复。不会补发启动前旧提示。

[在线展示页](https://aronlele.github.io/communications-assistant/)与安装包均公开访问，无需 GitHub 登录。安装包仍使用官方 TEST ONLY 配置、临时签名，未完成正式产品 API、Developer ID 签名及公证。不要通过关闭系统保护来宣称干净机器安装已验收。

## 验证结果与边界

173 项 Python 回归、26 项多账号原生检查、9 项恢复检查通过。实际打包引擎通过双账号演示及独立非登录环境的添加、移除、目录持久化、保留数据库检查；签名、DMG 和 ZIP 检查通过。

本机从 0.3.1 升级后，两个原有账号恢复连接；全部已保存设置与升级前一致（自动回复的启用时间更新），归档和发送账本未减少，之前开启的固定回复规则恢复开启。未为验收向实际工作机器人发送测试消息；不据此声称新增实际查岗已登记。

固定回复没有通用回执解析时仍只记录“已发送，登记未核实”。睡眠、合盖、退出及断网期间不能实时执行。0.3.1 的 72 小时观察因本次计划升级中断，不计为 0.3.3 连续通过；完整 VoiceOver、干净旧系统和新版长期稳定性仍待验收。
