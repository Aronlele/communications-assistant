安装前请了解

安装和升级

安装到“应用程序”中的“即讯”。系统可能要求管理员验证。请先退出正在运行的即讯；只关闭窗口仍会留在菜单栏运行。

安装器只替换应用，不修改现有账号、登录会话、归档、规则和发送账本。升级后请在应用内确认账号，并重新开启需要的自动回复。

首次使用

需要 Apple Silicon（M 系列芯片）。最低系统版本由本包检查；干净旧系统仍待验收。登录 Telegram 和收取消息需要可用网络。

应用在首次使用时按需请求系统通知权限。登录、凭据和用户资料由当前用户的应用管理，不在安装器的管理员进程中处理。

当前是测试包

本安装器未完成 Developer ID 签名及 Apple 公证，应用为临时签名。官方 TEST ONLY API 只适合测试；正式 API 及签名公证完成前，暂不面向普通用户正式推广。请勿关闭系统安全保护。
